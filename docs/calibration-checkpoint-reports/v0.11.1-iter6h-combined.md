## 4. 핵심 진단 — 왜 visibility gate가 abortion 완화 trade-off 해결 못 하는가

**핵심**: abortion 완화가 살리는 fruit이 **이미 cell_expansion 단계 진입한 fruit**.

```text
abortion 메커니즘 (CoreModel updateAbortionTracker):
- starvedDays는 actualDM/potentialDM < 0.25일 때 누적
- starvedDays >= ABORTION_LAG_DAYS (=4)에 abort
- cell_division 단계 fruit은 potential 자체가 작음 → ratio 잘 통과 → starvation 발생 안 함
- cell_expansion 단계 fruit은 potential 큼 → sink competition으로 ratio 낮아짐 → starvation → abort

abortion 완화 (0.25→0.18, lag 4→7):
- cell_expansion 단계 fruit이 starvation 회복 → 살아남음
- 이 fruit은 이미 diameter >= 3mm, phase = cell_expansion, gddSinceFert >= 200 등 모두 충족
- visibility gate 무력 (조건 다 통과)
```

→ **visibility gate는 "early-stage fruit이 너무 일찍 visible 진입"을 막는 도구**. 그러나 abortion 완화가 살리는 fruit은 early-stage가 아니라 **late-stage 살아남는 fruit**. lever 자체 가설 어긋남.
