## 3. Signal Verification Verdict

### 3.1 ✅ Signal is REAL at ensemble level
- baseline D90 visible avg = **4.20**
- HIT-1 D90 visible avg = **7.10** → **+2.90 improvement (+69%)**
- Range comparison: baseline [2, 6] vs HIT-1 [5, 10] → 모든 HIT-1 seeds가
  baseline range 상단 이상에서 시작 (5 ≥ 4.20)

### 3.2 ⚠ Iter 7's "12.17 average" is NOT reproducible at this scale
- Iter 7 averaged matrix 주장: cellDiv=200 × exp=0.08 → D90 vis 12.17 (220-seed avg)
- Iter 8 10-seed (cellDiv=200 alone): D90 vis avg 7.10 [5, 10]
- 가능한 해석:
  - Iter 7의 12.17은 cellDiv=200 + **exp=0.08** 조합 효과
    (본 verification에는 exp=0.08 미포함; baseline exp=0.10)
  - Iter 7의 averaging이 다른 axes (fSR 등)를 포함한 marginal effect였을 가능성
  - 220-seed가 더 큰 average 만들지만, 본 10-seed 결과로도 "+2-3 visible 증가" 방향은 확정
