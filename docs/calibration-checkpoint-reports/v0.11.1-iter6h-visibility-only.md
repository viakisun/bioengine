if (isVisible && visibilityGateMode !== 'diameter_only') {
  const phase = fruitPhase(f, ...).phase;
  isVisible = phase !== 'cell_division' && phase !== 'pre_fertilization' && phase !== 'aborted';

### 의미

이 결과는 **두 가지를 동시에 확정**:

1. **Visibility layer 분리 가능 검증** ⭐ — visibility filter 변경이 engine cohort/abortion/mass growth에 0 영향. 산출물 #5 (Growth Engine v1 reproductive layer 분리)의 영구 근거.
2. **Baseline에서 visibility 문제 없음** — baseline의 8 visible fruit이 모두 phase+GDD 조건 충족 = 자연스러운 visibility 진입. Day 30/33 = 0도 자연 유지.

### V_best 선정 (Round 2용)

baseline에 영향 없으므로 "가장 약한 effective gate" = **V3 (phase_and_gdd, GDD 80)** 선택 (Round 2에서 abortion 완화로 새 살아남은 fruit이 cell_division 단계 머무는 동안 차단 의도).

→ Round 2에서 abortion 완화 + V3 결합 → 진짜 효과 측정.
