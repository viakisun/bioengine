## 3. 핵심 발견

### 3.1 source는 vegetative biomass에 영향, visible cohort에 영향 X
A2 (LUE×1.4): source +473g (+44.5%) → vegetative +309g (+61%) **모두 vegetative로 흡수됨**.
fruit cohort survival (D90 cohort=18, visible=6)은 **baseline과 동일**.

→ source pool 자체는 cohort survival의 bottleneck이 아니다. 추가 source는 vegetative로
가지 cohort 살리는 데 안 쓰임.

### 3.2 sink balance 조정도 cohort 살리지 못함
B2 (sinkLeaf×0.5): vegetative 250g (vs baseline 507g, -51%) → leaf 안 자람, BUT visible cohort
동일 6. fruit으로 reallocate 안 되거나, 되도 cohort survival 못 회복.

→ sink imbalance도 cohort survival의 lever 아니다.

### 3.3 canopy lever는 source의 약한 amplifier
E2 (SLA×1.4): source +32g (+3%), vegetative +15g. SLA 단독은 leaf area를 키우지만,
canopy 이미 충분히 cover 중인 시점에서는 추가 source 미미.
