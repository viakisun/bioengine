  - flowersPerTrussMu ≥ 7에서 sink 분산 → Day 90 maxDiam 무너짐 (55 → 29mm)
- **다음 Iter 후보 (재조정 followUp)**:

  - **Iter 6f (Abortion Threshold / Starvation)**: `ABORTION_LAG_DAYS` (현재 4) 조정 또는 starvedDays trigger threshold (25% potential growth) 완화. abortion path 자체를 약화.
