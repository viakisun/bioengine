## 1. Executive Summary

**문제**: Iter 30 종료 후 시각 검증에서 leaf rotation 결함 (R4 fern stack, R5 size,
R6 horizontal stem) 발견. Iter 31 Phase 0~10에 걸쳐 R6/R5/R4 + R11~R26 _7회 leaf
rotation 산식 시도_ 끝에 R26 정답.

**R26 정답** (commit `4029b6b`, populateAnchorMorphology.ts:218-228):
```ts
if (edge.bonePath.length > 0) {
  const lastBone = edge.bonePath[edge.bonePath.length - 1];
  const petioleTipTangent = {
    x: lastBone.p1.x - lastBone.p0.x,
    y: lastBone.p1.y - lastBone.p0.y,
    z: lastBone.p1.z - lastBone.p0.z,
  };
  anchor.rotation = makeLeafQuaternion(petioleTipTangent, { x: 0, y: 1, z: 0 });
}
```

★ leaf rotation = PlantBase petioleCurve의 마지막 segment tangent _그대로_.
산수 _추가 0_ — populator는 _PlantBase 출력을 읽는 thin layer_.

**Cleanup**: 누적된 dead helper 8개 + 진단 spec 4개 + 디버그 코드 ~124줄 + console
spam ~43건 정리. **Phase Z numeric equivalence** (3-layer: position/rotation/vertex
hash)로 _byte-level 동일성_ 증명.
