## 4. ⭐⭐ Root Cause #1 — CoreModel.ts Truss Emergence Bug (SSOT #168)

### Pre-fix (2 사이트 — 분 단위 + 일 단위 path):
```ts
const expectedTrussCount = Math.floor(
  Math.max(0, (state.TT - cultivar.GDD_to_first_flower) / cultivar.GDD_per_truss) + 1,
);
```

At TT=0.005 (Day 0):
- `max(0, (0.005 - 300) / 100)` = 0
- `0 + 1` = `floor(1)` = **1** → emergeTruss fires AT TRANSPLANT

`+1` outside `max(0, ...)` clamps minimum to 1 — 절대 0 안 됨. T1이 항상 Day 0 emerge.

### Iter 16 fix (CoreModel.ts:461-466 + 832-836):
```ts
const expectedTrussCount = state.TT < cultivar.GDD_to_first_flower
  ? 0
  : 1 + Math.floor((state.TT - cultivar.GDD_to_first_flower) / cultivar.GDD_per_truss);
```

With App climate T=23, T_eff=13/day, T1 emerges at TT=300 → **Day 23** (정상 첫 1화방 timing).

## 5. ⭐ Root Cause #2 — UI plantStageLabel Trigger Over-fire (SSOT #165)

### Pre-fix (FloatingTopBar.tsx + BottomPlaybackBar.tsx 동일):
```ts
if (ps.trusses.length === 0) return '영양생장기';
if (anyRipe) return '수확기';
if (ps.trusses.some(t => t.fruits.length > 0)) return '착과비대기';  // ← bud도 trigger
return '개화기';
```

`fruits[]` array에는 fertilized fruit + flower bud + aborted 모두 포함. 어떤 truss든
하나 emerge하면 `flowerCount`개 bud slot 즉시 생성 → `fruits.length > 0` → "착과비대기"
firing.

### Iter 16 fix (4-bucket discrimination):
```ts
let hasRipe = false, hasExpanding = false, hasFertSmall = false, hasBud = false;
for (const t of ps.trusses) for (const f of t.fruits) {
  if (f.harvested || f.aborted) continue;
  if (f.ripenStage >= 4) hasRipe = true;
  else if (f.diameter >= 10) hasExpanding = true;
  else if (f.fertilizationTT > 0) hasFertSmall = true;
  else hasBud = true;
}
if (hasRipe) return '수확기';
if (hasExpanding) return '착과비대기';
if (hasFertSmall) return '착과기';
if (hasBud) return '화방 분화기';
return '영양생장기';
```

새 단계: **영양생장기 / 화방 분화기 / 착과기 / 착과비대기 / 수확기** (5 단계).
