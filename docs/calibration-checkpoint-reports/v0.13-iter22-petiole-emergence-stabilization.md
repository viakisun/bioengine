## 2. n16/n10 outlier 원인 분석 (왜 5cp가 thick stem에선 한계인가)

n16 detail:
- exp radial = 7.22mm (bio stem 표면)
- fv radial = 14.14mm (firstVisible at c0 position 자체)
- fv Δy = -2.22mm
- emergeGap = 7.26mm

메커니즘:
1. c0 = attachPos + radial × (tipR × 0.05). D99 long petiole에서 tipR ~150mm
   → c0 radial offset = 7.5mm. attachPos(7.22) + 7.5 = 14.7mm radial.
2. 5cp Catmull-Rom에서 c0는 parametric 1/4 위치. 첫 segment (attachPos →
   c0)가 curve 전체 길이의 25%를 차지.
3. parentCtx.radius (swollen render radius) ≈ 8-9mm for D99 n16 위치.
   attachPos(7.22) ↔ c0(14.7) 사이 catmull-rom 보간 — 1차 미분이 phantom
   cp 영향 받아 inward wobble 가능 → 첫 sample들이 swollen threshold(8-9mm)
   를 늦게 통과.
4. firstVisible이 사실상 c0 자체에서 검출 → emergeGap ≈ |attachPos - c0| ≈ 7mm.

D45는 짧은 petiole + 얇은 stem(4.8mm swollen)이라 c0(11mm radial)이 surface를
충분히 멀리 떨어진 점에 위치 → 첫 sample 1-2개 만에 threshold 통과 → emerge
~3mm.

**즉 5cp는 thin stem에 잘 동작, thick stem에선 c0 위치가 너무 멀어 parametric
curve가 천천히 도달.**

## 3. Q1 outlier (n16 2.23mm) — fundamental swelling tension

```text
parentSwellingScale = 1.25 (junction weld 효과)
bio_radius (PlantBase) = 7.22mm
swollen_radius = 7.22 × 1.25 = 9.03mm
embedDepth = 1mm (Iter 21 Fix 3)

childStart radial = swollen - embed = 9.03 - 1.0 = 8.03mm
graphRoot (attachPos) radial = bio = 7.22mm
gap_radial = |8.03 - 7.22| = 0.81mm
+ Y offset (parent bone interpolation residual) ≈ 1-2mm
= Q1 ~2.23mm
```

선택:
- **embed UP → Q1 down, occlusion up** (Iter 18~20)
- **embed DOWN → occlusion down, Q1 up** (Iter 21)
- 둘 다 충족 = parentSwellingScale 1.25 → ~1.0 변경 필요 (다른 tradeoff: junction weld 손실)

**Q1 fundamentally tied to parentSwellingScale**. Iter 22 scope 밖.
