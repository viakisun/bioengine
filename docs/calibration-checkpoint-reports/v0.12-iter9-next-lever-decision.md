## 3. Iter 10 핵심 가설 — Phase Transition Smooth

### 3.1 현재 구조 (binary)
```text
if gddSinceFert < cellDivisionDurationGDD:
    phase = cell_division
    stepDemand = baseDemand × cellDivisionStepDemandFraction  (Iter 9, 0.10)
elif gddSinceFert < cellExpansionEnd:
    phase = cell_expansion
    stepDemand = baseDemand × expansionPhaseGrowthMultiplier  (1.0)
```

문제: GDD threshold tick 직후 fruit mass demand가 0.10 → 1.0 **즉시 10× 증가**.
이로 인해 D33 시점 fruit이 transition 직후 빠르게 mass 채워 D33 mx 4-7mm.

### 3.2 Iter 10 sigmoid transition zone
```text
if gddSinceFert < cellDivStart:                       # cell_division 초반
    multiplier = cellDivisionStepDemandFraction       (0.10)
elif gddSinceFert < cellDivisionEnd:                  # cell_division 후반 (transition zone)
    progress = (gddSinceFert - cellDivStart) / (cellDivisionEnd - cellDivStart)
    sigmoid_t = (progress - 0.5) / transitionWidth
    multiplier = cellDivisionStepDemandFraction + 
                 (1.0 - cellDivisionStepDemandFraction) × sigmoid(sigmoid_t)
elif gddSinceFert < cellExpansionEnd:                 # cell_expansion 초반 (transition tail)
    progress = (gddSinceFert - cellDivisionEnd) / transitionWidth
    multiplier = expansionPhaseGrowthMultiplier × (1 - exp(-progress))  # gradual ramp up
```

이렇게 하면:
- cell_division 후반에 fruit mass demand가 0.10 → 1.0으로 **smooth하게** 증가
- D33 시점 fruit이 transition zone 안에 있어 mass 천천히 채워 maxDiam ≤ 3mm 유지
- cell_expansion 진입 후 점진적으로 정상 rate 회복 → D90 maxDiam in band
