## 2. 최종 fix (acfad71) — 3 commit 누적

### 2.1 b77df4d — `leafMesh.position = attachPos` (Iter 22, 폐기)

mesh.position을 PlantBase attachPosition으로. mesh-local origin이 그 위치라
가정. **잘못된 가정** — leafChunk 출력 vertex는 `(petioleLen, 0, 0)`부터 시작.

### 2.2 fbb0c2e — `leafMesh.position = tip` 복귀 + vertex shift petioleLen

mesh.position을 petiole tip으로 되돌림 + leafChunk.positions의 모든 x에서
petioleLen 빼기. **부분 fix** — vertex.x_min이 0이 아닌 rachisLen×0.15.

### 2.3 acfad71 — 정확한 vertex shift (min x = 0)

```ts
// LeafGenerator.ts
let minX = Infinity;
for (let i = 0; i < chunk.positions.length; i += 3) {
  if (chunk.positions[i] < minX) minX = chunk.positions[i];
}
if (Number.isFinite(minX) && minX !== 0) {
  for (let i = 0; i < chunk.positions.length; i += 3) {
    chunk.positions[i] -= minX;
  }
}
```

chunk의 실제 `min x`를 측정해 그만큼 shift → 첫 leaflet vertex가 mesh-local
`(0, 0, 0)`. `leafMesh.position = tip` 설정 시 leaflets가 정확히 petiole
tip 위치에서 시작.

**시각 확인**: 사용자 "아 이제 제대로 됐다" (acfad71 직후).
