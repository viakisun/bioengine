=================================================================
산출물 #10 — 운용 데모 녹화 (Demo Recording)
=================================================================

이 위치(`delivery/`)에 사용자가 직접 녹화한 운용 데모 영상을 두십시오.

권장 파일명     10_Demo_Recording.zip (zip 내부에 mp4 또는 webm)
권장 시나리오   phenotyping-D110-survey 1회
                — 부팅 → Picker → Workbench 진입
                → START SURVEY → 좌측 베드 페노타이핑 서베이
                → 결과 시트 갱신
                → 히스토리 드로어 (선택)
권장 길이       4~6분
권장 포맷       mp4 (H.264) 또는 webm (VP9)
권장 해상도     1280×720 이상 (1920×1080 권장)
프레임 레이트   30 fps 이상

영상에는 다음이 모두 포함되어야 합니다.
- 화면 캡처 (전체)
- 음성 (해설 또는 자막)
- 부팅 → 시나리오 진입 → 서베이 → 결과 sheet 전체 흐름

녹화 도구는 자유 선택입니다.  macOS QuickTime, OBS Studio,
Snagit, Loom, Playwright video 모두 가능합니다.

녹화 zip을 이 위치에 넣은 후 본 NOTE 파일은 삭제하셔도 됩니다.
이후 MANIFEST.json도 갱신해 주십시오 (수동 또는 build_delivery
재실행).

자세한 절차는 `06_User_Manual.pdf` 의 §7 "적심·적과 관제 시연
절차" 를 참고하세요.
