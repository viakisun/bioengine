# 업체 제출요청 문구 작성 프롬프트

아래 기준정보를 바탕으로 업체에 보낼 제출요청 메시지를 작성하라.

요청 문서는 보통 다음과 같다.

- 견적서
- 계약서 날인본
- 사업자등록증
- 통장사본
- 거래명세서
- 전자세금계산서

문구 원칙:

- 업체가 바로 처리할 수 있도록 날짜, 품명, 수량, 금액을 명확히 쓴다.
- 품명은 거래문서에 들어갈 짧은 명칭을 사용한다.
- 비고란에는 과업 목적을 짧게 쓸 수 있으나, 업체 범위가 아닌 개발 내용을 품명에 넣지 않는다.
- 공급일자, 작성일자, 발행요청일을 구분한다.
- 너무 딱딱하지 않되, 정산 증빙용 문서임이 분명해야 한다.
