# 문서 패키지 생성 프롬프트

아래 입력 JSON을 기준으로 정부연구개발사업 증빙 문서 패키지를 생성한다.

작성 원칙:

1. 문서는 grayscale, 공공 R&D 정산 및 내부 결재에 적합한 전문 문체로 작성한다.
2. 기안서에는 업체명과 금액을 확정값으로 넣지 않는다.
3. 과업지시서는 업체 수행 범위, 내부 수행 범위, 제외 범위를 명확히 분리한다.
4. 발주서와 계약서부터 업체명, 금액, 계약기간을 반영한다.
5. 검수확인서는 납품일, 검수일, 검수 항목, 검수 결과를 중심으로 작성한다.
6. 완료보고서는 진행 경과, 납품 산출물, 검수 결과, 종합 의견만 간결하게 작성한다.
7. 모든 문서의 날짜, 품명, 업체명, 금액, 산출물명은 서로 정합해야 한다.
8. 업체가 발행해야 하는 견적서, 거래명세서, 세금계산서는 생성하지 말고 요청 기준만 작성한다.

생성 후 반드시 정합성 검수표를 작성한다.
