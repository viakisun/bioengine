# 정합성 및 완성도 검수 프롬프트

생성된 문서 패키지를 검수하라.

검수 범위:

- 문서 순서가 자연스러운가
- 기안서 → 과업지시서 → 견적서 → 발주서 → 계약서 → 납품 → 검수 → 완료보고 → 세금계산서 → 이체확인증 흐름이 맞는가
- 기안서에 업체명과 금액이 들어가지 않았는가
- 발주서/계약서에는 업체명, 금액, 계약기간이 들어갔는가
- 검수확인서와 완료보고서의 납품일/검수일이 맞는가
- 품명과 산출물명이 모든 문서에서 일관되는가
- 업체 수행 범위와 발주기관 내부 수행 범위가 혼동되지 않는가
- 업체 수취 문서 요청 기준이 명확한가
- 완료보고서가 과도하게 장황하지 않은가

출력:

1. 전체 정합성 결론
2. 우선순위별 이슈 목록
3. 문서별 완성도 점수
4. 수정 권고안
